Icon assets in this directory include source files and generated PNG files used
for the bundled MapLibre sprite.

Some SVG icon source files are based on data from Styles4DMinQGIS:
https://github.com/yamamoto-ryuzo/Styles4DMinQGIS

The SVG files in Styles4DMinQGIS are distributed under CC0 1.0 Universal
(Public Domain Dedication):
https://creativecommons.org/publicdomain/zero/1.0/

Some icon source files were created or modified for this project and are not
part of the original Styles4DMinQGIS distribution.
